# batchsample2


## Prerequisites

- Java 21+
- Docker (for Kafka and Kafka-UI)

## Infrastructure

Start Kafka and Kafka-UI using Docker Compose:

```bash
docker compose up -d
```

| Service   | URL                    |
|-----------|------------------------|
| Kafka     | `localhost:9092`       |
| Kafka-UI  | http://localhost:8080  |
